Telegram Message Forwarder – Full Guide

1. What does this project do?

This is a tiny Telegram bot that automatically forwards every new message (and optionally old messages) from one Telegram channel/group to another. It remembers the last processed message ID so you can resume after a restart.

2. Required Telegram credentials

To talk to Telegram you need an API ID and API Hash. Obtain them at my.telegram.org → “API Development tools” → “Create new application”.
API_ID is a numeric integer.
API_HASH is a 32‑character hex string.

If you already have a session string (the value Telethon saves after a login) you can skip entering the API ID/Hash – just paste the session string on the Config page.

3. Deploy the code

  1. Clone or download this repo to your server/PC.
  2. Create a virtual environment (recommended):
    python -m venv venv
    source venv/bin/activate (Linux/macOS) or venv\\Scripts\\Activate (Windows).
  3. Install dependencies:
    pip install -r requirements.txt
  4. Run the Flask web UI:
    python app.py
    The console will show something like Running on http://0.0.0.0:5000.
  5. Open that URL in a browser (or use the URL provided by your hosting platform, e.g. Railway, Render, Fly).

4. Configure the bot (first run)

  1. Config page (/config): enter your API_ID, API_HASH and optionally a SESSION_NAME. If you already have a session string you can paste it in the SESSION_STRING field (skip the OTP steps).
  2. Click Save & continue – the values are written to .env.

5. Log in with phone + OTP

  1. Go to /login and type your Telegram phone number with country code (e.g. +14155552671).
  2. Press Send OTP – you will receive a 5‑digit code via SMS (or Telegram).
  3. Go to /otp and enter the code, then press Verify.
  4. After verification the app stores a SESSION_STRING in .env so you won’t need to type the code again.

6. Pick source & target channels

  1. Open /channels. You will see two small tables labelled From and To showing the current channel IDs (taken from .env).
  2. Below them is a list of every channel/group you belong to. Click the Change button next to From or To, select the desired channel from the list, and the ID is saved.
  3. If you need a channel that is not in the list, use the Add custom channel / group field: paste a Telegram link (t.me/...) or username (@mychannel) and click Add. The app resolves the entity and writes its ID (by default it overwrites the From channel – you can edit the code to target the To channel instead).
  4. After you’ve set both IDs, close the browser.

7. Run the forwarder

Now .env contains the needed values. Simply run the original forwarder:

python forwarder.py

The script will start forwarding every new message from the selected source to the target, and it will resume from the last saved message ID if you restart it.

8. (Optional) Deploy on a PaaS (Railway, Render, Fly, etc.)

  1. Push this repository to a Git host (GitHub, GitLab, Bitbucket).
  2. Create a new project on the PaaS and point it at the repo.
  3. The platform will run python app.py (or you set the start command).
  4. Make sure the .env file is present in the project root; the web UI will write to it on first run, or you can pre‑populate it with your API credentials.
  5. Once the deployment is up, open the generated URL and follow the same Config → Login → Channels flow.

Built with Telethon + Flask. Feel free to fork and adapt.
