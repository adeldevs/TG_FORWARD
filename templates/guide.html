Telegram Message Forwarder – Quick Start & User Guide

1. Overview

This web application allows you to automatically forward messages from one or more Telegram channels/groups to one or more destination channels/groups in real time.

2. Step 1: Telegram API Credentials

Visit the Config page. You only need your Telegram API credentials:

  • API_ID: Obtained from my.telegram.org.
  • API_HASH: 32-character hexadecimal string from my.telegram.org.
  • Note: You no longer need to type any channel IDs in the config!

3. Step 2: Log In with Phone & OTP

  1. Go to Login and enter your Telegram phone number with international country code (e.g. +918129211707).
  2. Check Telegram on your devices for the 5-digit verification code.
  3. Enter the code on the OTP page. If your Telegram account has Two-Step Verification (2FA cloud password) enabled, enter your password as well.

4. Step 3: Select Source & Destination Channels

Once logged in, open Channels:

  • Interactive Table: All channels and groups where your account is a member are listed with their full channel names.
  • Multiple Selection: Use the checkboxes in the table to pick one or more Source channels and one or more Destination channels.
  • Public Channels: If a source or destination is a public channel, use the "Add Custom or Public Channel" box with its @username or t.me/... link. It will automatically resolve the channel name and add it!
  • Save Selection: Click "Save Channel Selection" to apply.

5. Step 4: Media Filter & Forwarder Controls

  • Media Filter: Choose whether to forward all messages or filter by photos, videos, audio, text, or documents.
  • Live Forwarder: The forwarder runs automatically in the background. You can pause or resume it anytime from the Channels dashboard.

6. Logging Out & Resetting Data

Click the Log Out button in the top navigation bar at any time. This will disconnect your Telegram session, terminate the login, and wipe all saved channels, state, and session files for complete privacy.
